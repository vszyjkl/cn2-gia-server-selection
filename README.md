## CN2 GIA 优化的到底是哪一段路

CN2 是中国电信的下一代承载网，分 GT 和 GIA 两个等级，两者都涉及 59.43 段，区别在于从哪一段开始走。

GIA 全程走 59.43，双向不碰 202.97。去程从国内省级出口直接进入 AS4809 网络，回程同样从机房经 59.43 节点回国，中间不经过 163 骨干网。

GT 是“国内走老路，国际走新路”。省级骨干段仍然是 163 的 202.97，到国际出口附近才切到 59.43。晚高峰丢包通常在 2%–5%，延迟抖动比 GIA 明显。

普通 163 骨干网（AS4134）覆盖广、成本低、没有优先级保障。白天延迟 150–200ms，北京时间 20:00 以后国际出口被挤满，延迟能突破 250ms，丢包率 5% 以上。

同样标着“美国服务器”，晚高峰体验差出一倍，差的就是这一段。

## 美国CN2 GIA服务器怎么验线路

市面上的“伪 GIA”不少，只优化去程、回程还走 163 的机器很常见。三步就能看出来：

1. 在服务器上 `traceroute` 到国内电信 IP，看回程路径。全程出现 59.43 开头的节点才算数，混进 202.97 说明国内段掉回 163 了。

## 800GB 双向流量，双向是什么意思

上传和下载都算。800GB/月指上下行加起来 800GB，并非“下载 800GB”。

建站场景里，访客拉页面算下行；你 SSH 传文件、跑备份、`apt`/`yum` 更新、`rsync` 同步、拉 Docker 镜像，全都算。每天往异地备份 5GB，一个月就是 150GB 上传，差不多吃掉五分之一。图片站、带视频的站，下行掉得更快。

买之前按“下行 + 上行”各估一遍，别只算访客流量。超了流量会怎样，公开资料里没写清楚，下单前问一句客服比较稳。
